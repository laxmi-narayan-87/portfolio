# Portfolio illustrations

Four original, lightweight SVG illustrations authored for this portfolio branch, with English labels and an intentionally sketch-like black-line style:

- `hero-curiosity.svg` — turning questions into working software.
- `darksense-inspection.svg` — inspecting text, layout, and interaction flow for potentially manipulative patterns.
- `skillforge-path.svg` — an adaptable learning path with goal, learn, check, and next steps.
- `qa-test-before-trust.svg` — checking a test scenario and recording expected versus actual behaviour.

These are hand-authored SVG sketches, **not** AI-generated images. The illustration generator was unavailable due to an account credit quota error. All SVGs use vector paths and embedded English labels; no external image dependencies are required.

To integrate in HTML, use a `figure` with an inline SVG or an `img` pointing to the SVG. Include `illustrations.css` only where its presentation classes are used.
