SkillForge Academy

A personalized learning platform that combines curated learning roadmaps, AI-assisted roadmap generation, interactive topic assessments, and persistent learner progress.

Problem

Learning plans can be difficult to personalize and track. SkillForge explores a workflow that connects learner goals with a structured roadmap, topic assessments, and saved progress.

Implemented workflow

  1. Use learner context such as skill level, career goal, and learning preferences.
  2. Generate a roadmap with Gemini and validate its structure with Zod.
  3. Display the learning path as an interactive graph using React Flow.
  4. Connect topic assessments to roadmap data.
  5. Persist authentication and user-scoped progress using Supabase.

The repository documents curated roadmaps, assessment-based skill-level updates, learning resources, TanStack Query, and responsive UI components.

Architecture and safety considerations

The project focuses on product engineering around an AI feature rather than claiming novel model research. Generated roadmap data should be validated before use. The repository documents Row Level Security requirements for user-owned data and notes that the required migration must be applied before production use.

Run and verify

The README documents local setup and the verification commands npm run lint and npm run build. Consult the repository for current setup requirements and deployment status.
